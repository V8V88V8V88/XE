# Project Status

## Current state

XE is pre-alpha. The full compiler pipeline is present:

- lexer
- parser
- semantic analysis
- code generation
- CLI entrypoint

## Implemented language features

- `print(...)`
- `input(prompt)`
- `length(value)`
- `type(value)`
- `convert(value, target_type)`
- `if` / `else`
- `repeat N times`
- user-defined functions
- recursion
- list literals and indexing
- arithmetic, comparison, and boolean operators

## Planned work

- `while` loops
- `for` loops
- file I/O
- networking
- concurrency
- modules and `import`
- formatter
- debugger
- IDE support
- richer built-ins like `floor`, `ceil`, `min`, and `max`
